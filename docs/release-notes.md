# 正式发布正文

正式模板的中央来源是 `templates/repository/.github/release-template.md.mustache`。Copier 将其递送到产品 `.github/release-template.md.mustache`；构建预检核对产品 S 与执行器提交中的模板字节。产品 `.release-notes/<unitId>.md` 是候选审阅文稿，保留在产品源码中，后续由同一候选的生成和编辑保护流程维护。

单位说明包含概述、更新内容、兼容性、升级与迁移、安装说明、已知问题、恢复七节。渲染器提取原文，只在展示副本调整下级标题；中文、链接、代码和 HTML 保留。缺节、重复标题、未填写提示、未知模板变量、动态或不安全的模板用法会使构建失败。

公开正文按升级须知、更新内容、可选贡献者、完整变更排列。产品名使用已冻结单位 ID；版本、源码提交和执行器提交来自同一构建记录。下载表使用该单位冻结资产映射的 ID、构建目标和文件名，准确 tag 经编码后组成 GitHub Release 链接；ID 对应的用途和安装方法见已审安装说明。首次发布明确标注，完整变更链接指向源码提交。CHANGELOG 继续提供版本技术记录与比较来源。

贡献者使用该候选已冻结的原生身份，排除已核实作者和机器人，按数字 ID 排序。头像与主页属性使用 Mustache 默认转义，空集合省略整个贡献者节。渠道在公开时标为待分发，实际完成另由原生证据验收。

相同输入生成相同字节，`release-notes.md` 与公开 Release body 一致。模板变更从下一候选采用；历史已公开正文保持原字节。LayerScape 作者沿用已核实的 axiomoth 身份，首次接入保留原六节说明并补齐更新内容。
