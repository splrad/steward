# 正式发布正文

正式模板的中央来源是 `templates/repository/.github/release-template.md.mustache`。Copier 将其递送到产品 `.github/release-template.md.mustache`；构建预检核对产品 S 与执行器提交中的模板字节。产品 `.release-notes/<unitId>.md` 是候选审阅文稿，保留在产品源码中，后续由同一候选的生成和编辑保护流程维护。

单位说明包含概述、更新内容、兼容性、升级与迁移、安装说明、已知问题、恢复七节。渲染器提取原文，只在展示副本调整下级标题；中文、链接、代码和 HTML 保留。缺节、重复标题、未填写提示、未知模板变量、动态或不安全的模板用法会使构建失败。

公开正文按升级须知、更新内容、可选贡献者、完整变更排列。单位可在 delivery 声明 `displayName`，省略时使用仓库名称。下载列表采用冻结文件名、准确 tag 和同一资产的 `description` 用途说明。源码或比较链接指向本次冻结提交。

贡献者使用该候选已冻结的原生身份，排除已核实作者、机器人和已识别服务身份（包括 GitHub `web-flow` 的原生 ID `19864447`），按数字 ID 排序。API 的 `type=User` 本身不能证明真人身份。头像与主页属性使用 Mustache 默认转义，空集合省略整个贡献者节。

开放候选的来源、作者配置和单位映射一致时，执行器可由保留的原生 actors 重算派生贡献者投影；原始身份、内容缓存和人工文件保持。编辑暂停仍显示暂停提示，人工冲突显示绑定当前 head 的保护提示，避免把旧生成预览当作当前人工正文。刷新不触发模型生成或候选推送。冻结投影采用新身份规则后，后续构建执行器也须支持同一规则；旧执行器重新校验原生 actors 可能因投影不同而拒绝构建。

常规发布直接使用签名附件 `release-notes.md` 的字节作为正文。LayerScape v1.0.0 的单次排版修订绑定到原仓库 ID、Release ID、tag、源码及两个精确正文摘要。回读仍检查不可变附件和 tag，历史生产凭据可使用原签名正文重算。
