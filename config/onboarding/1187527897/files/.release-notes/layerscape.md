## 概述

本文件初始化 LayerScape 的发布输入合同，当前产品版本为 9.2.2。后续候选的具体变化以同一提交中的 CHANGELOG 对应版本条目为准。

## 兼容性

产品目标为 Windows x64 和 AutoCAD 2018 至 2027。各宿主项目沿用原目标框架及 API 分支；本次本地构建覆盖全部十个宿主项目，但尚未在真实 AutoCAD 进程中逐版本验证加载、字体替换和升级行为。

## 升级与迁移

使用部署器前退出 AutoCAD，并备份已有字体、映射和自定义路径配置。本次接入保留 VERSION=9.2.2，不涉及配置或数据格式迁移。后续版本若改变数据格式，须在该候选中补充迁移步骤后发布。

## 安装说明

普通用户使用对应版本的 AFR-Deployer 安装程序；手工部署使用同一 Release 的 AFR-DLL 压缩包，字体资源来自该 Release 的 Fonts.zip。先核对版本、文件集合和 SHA256SUMS，再按原项目安装指引操作；包渠道的完成状态以实际分发记录为准。

## 已知问题

本次验证仅覆盖构建、文件格式和发布合同。真实 AutoCAD 宿主内的运行、升级及用户数据恢复尚未验证，不能据此确认这些场景无问题。

## 恢复

恢复前退出 AutoCAD，记录当前安装版本并保留配置和字体备份。从之前已验证版本的准确 Release 取回安装文件，恢复对应配置，再在使用的 AutoCAD 版本中验证加载和字体映射。当前接入下界为 [v9.2.2](https://github.com/splrad/LayerScape/releases/tag/v9.2.2)；接入下界本身不证明该版本已在当前用户环境中完成恢复验证。
